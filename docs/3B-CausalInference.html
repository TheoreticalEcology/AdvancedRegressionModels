7  Causal inference

NoteIn this chapter

In this chapter, you will learn

  • what a causal effect is, and how experiments and statistical control (adjustment) remove confounding (Section 7.1, Section 7.2);
  • which variables to include in a regression: confounders yes, colliders no, mediators depending on the question, using causal graphs to decide (Section 7.3, Section 7.4);
  • how to report the result without the Table 2 fallacy, how to estimate whole graphs with structural equation models, and how to partial out confounders (Section 7.4.1, Section 7.4.2, Section 7.5).

Workflow steps (Section 1.1.2): step 1 (question and goal), step 3 (choice of predictors).

Prerequisites: the linear model (Chapter 2), in particular multiple regression (Section 2.7).

7.1 Correlations != causality

The most fundamental distinction in strategies for model choice is if we want to estimate effects, or if we want to predict. If we want to estimate effects, we nearly always want to estimate causal effects. Prediction is treated in the chapter on model selection (Chapter 8).

Let me first define what we mean by “a causal effect”: if we have a system with a number of variables, the causal effect of A on B is the change in B that would happen if we intervened on A (set it to a different value), while everything not caused by A is left unchanged. This total effect includes paths through mediators; the direct effect excludes them.

Assume we look at the effect of coffee consumption on Lung Cancer. Assume further that there is no such effect. However, there is an effect of smoking on lung cancer, and for some reason, smoking also affects coffee consumption.

It is common to visualize and analyze such relationships in a causal graph. Here, I use the ggdag package

library(ggdag)
library(ggplot2)
theme_set(theme_dag())
dag = confounder_triangle(x = "Coffee", y = "Lung Cancer", z = "Smoking") 
ggdag(dag, text = FALSE, use_labels = "label")

We can use the ggdag package (or to be more exact: the underlying daggitty package) to explore the implications of this graph. The way I created the graph already includes the assumption that we are interested in the effect of Coffee on Lung Cancer. I can use the function ggdag_dconnected() to explore if those two are d-connected — a technical term for whether two variables may be statistically associated given a particular conditioning set (i.e. which other variables are controlled for).

ggdag_dconnected(dag, text = FALSE, use_labels = "label")

In this case, the plot highlights me to the fact that Coffee and Lung cancer are d-connected (with an empty conditioning set, i.e. without controlling for anything). What that means is: if I plot coffee against lung cancer, I will see a correlation between them, even though coffee consumption does not influence lung cancer at all. Note that d-connection is a property of the graph: it tells us which associations we should expect in the data, not that there is a causal link between the two variables — here, the association is entirely created by the common cause Smoking. We can easily confirm via a simulation that this is true:

smoking <- runif(50)
Coffee <- smoking + rnorm(50, sd = 0.2)
LungCancer <- smoking + rnorm(50, sd =0.2)
fit <- lm(LungCancer ~ Coffee)
plot(LungCancer ~ Coffee)
abline(fit)

So, if we would fit a regression of LungCancer ~ Coffee, we would at least conclude that there is a correlation between the two variables. Many people would even go a step further, and conclude that Coffee consumption affects lung cancer. This is a classical misinterpretation created by the confounder smoking. Realizing this, I could ask the ggdag_dconnected function what would happen if I control for the effect of smoking.

ggdag_dconnected(dag, text = FALSE, use_labels = "label", controlling_for = "z")

The result conforms with our intuition - once we control for smoking, there will be no correlation between Coffee and Lung Cancer (because there is no causal effect between them). In causal lingo, we say the two are now d-separated.

7.2 How to control?

But how do we control for the confounder smoking?

7.2.1 Experimental control

The conceptually easiest approach is: we perform a controlled experiment. The entire idea experiments is that we vary only one (or a few) factors, keeping the others constant, and thus we are able to “see” causal effects directly. So, if we did an experiment with people that all smoke the same, varying coffee, we would get the right result:

smoking <- rep(0.5, 50)
Coffee <- smoking + rnorm(50, sd = 0.2)
LungCancer <- smoking + rnorm(50, sd =0.2)
fit <- lm(LungCancer ~ Coffee)
plot(LungCancer ~ Coffee)
abline(fit)

This leads us to an important point: randomized controlled experiments estimate causal effects, provided the randomization (and compliance, blinding) worked. Actually, all advice regarding experimental design (control, randomization) is aimed at removing any possible confounding with other factors, so that we can isolate causal effects.

7.2.2 Statistical control (adjustment)

In observational data, we have to use statistical methods to achieve statistical control. Luckily, we have a great tool for that: the multiple regression (see Section 2.7).

The multiple regression can estimate the effect of coffee, corrected for the effect of smoking. Thus, by including smoking in the multiple regression, we are “virtually” holding smoking constant, thus allowing us to estimate the causal effect of coffee. Let’s try this out:

smoking <- runif(100)
Coffee <- smoking + rnorm(100, sd = 0.2)
LungCancer <- smoking + rnorm(100, sd =0.2)
fit1 <- lm(LungCancer ~ Coffee)
fit2 <- lm(LungCancer ~ Coffee + smoking)
plot(LungCancer ~ Coffee)
abline(fit1)
xs <- seq(min(Coffee), max(Coffee), length.out = 50)
lines(xs, predict(fit2, data.frame(Coffee = xs, smoking = mean(smoking))), col = "red")
legend("topleft", c("simple regression", "multiple regression"), col = c(1,2), lwd = 1)

The red line shows the effect of coffee with smoking held at its mean: it is much flatter than the simple regression, i.e. most of the apparent coffee effect disappears once we control for smoking.

Tip

GAMs (see Section 2.5.3) are particularly useful for confounders. If you have confounders, you usually don’t care that the fitted relationship is a bit hard to interpret, you just want the confounder effect to be removed. So, if you want to fit the causal relationship between Ozone ~ Wind, account for the other variables, a good strategy might be:

7.3 A framework for causal analysis

What we have just seen in the section on statistical control (Section 7.2.2) is an example of a causal analysis. The goal of a causal analysis is to control for other variables, in such a way that we estimate the same effect size we would obtain if only the target predictor was manipulated (as in a randomized controlled trial). If we are after causal effects, the correct selection of variables is crucial, while it isn’t if we just want to predict (see the chapter on model selection, Chapter 8).

You probably have learned in your intro stats class that, to do so, we have to control for confounders. I am less sure, however, if everyone is clear about what a confounder is. In particular, confounding is more specific than having a variable that correlates with predictor and response. The direction is crucial to identify true confounders. Imagine that there is a third variable (nervousness) that is influenced by both coffee and lung cancer:

dag = collider_triangle(x = "Coffee", y = "Lung Cancer", m = "Nervousness") 
ggdag(dag, text = FALSE, use_labels = "label")

Let’s simulate some data according to this structure

set.seed(123)
Coffee <- runif(100)
LungCancer <- runif(100)
nervousness = Coffee + LungCancer + rnorm(100, sd = 0.1)

If we fit a multiple regression on this structure, we erroneously conclude that there is an effect of coffee on lung cancer (note the strongly negative coefficient: conditioning on a collider induces a spurious negative association)

fit1 <- lm(LungCancer ~ Coffee + nervousness)

What we’ve seen here is a collider bias - a collider is a variable that is influenced by predictor and response. Although it correlates with predictor and response, correcting for it (or including it) in a multiple regression will create a bias on the causal link we are interested in (Corollary: Including all variables is not always a good thing).

There is an entire framework to analyze which variables you need to include in the regression to achieve proper control (Pearl, 2009). In the following picture, I have summarized the three basic structures. The one that we haven’t discussed yet is a mediation structure. A mediator is an intermediate variable that “mediates” an effect between exposure and response.

Pearl, J. (2009) Causality: Models, reasoning, and inference. 2nd ed. Cambridge University Press.

How do we deal with the basic causal structures colliders, mediators and confounders in a regression analysis? Start by writing down the hypothesis / structure that you want to estimate causally (for example, “Plant diversity” -> Ecosystem productivity in the figure above). Then

  1. Control for all confounding structures
  2. Do not control for colliders and other similar relationships, e.g. “M-Bias” (red paths).
  3. It depends on the question whether we should control for mediators (yellow paths).

Note: If other variables are just there to correct our estimates, they are nuisance parameters (= we are not interested in them), and we should later not discuss them, as they were not themselves checked for confounding (Table 2 fallacy, see Section 7.4.1).

Another great paper is Laubach et al. (2021).

7.4 Graphs and models on graphs

A nice walk-through of finding adjustment sets with ggdag is the blog post Closing backdoors with DAGs by Andrew Heiss.

Let’s take a more complicated example. We will use data from Grace and Keeley (2006), who try to understand plant diversity following wildfires in fire-prone shrublands of California. The authors have measured various variables, and they have a specific hypothesis how those are related (see below).

Grace, J.B. and Keeley, J.E. (2006) “A structural equation model analysis of postfire plant diversity in California shrublands,” Ecological Applications, 16(2), pp. 503–514. Available at: https://doi.org/10.1890/1051-0761(2006)016[0503:ASEMAO]2.0.CO;2. 
library(piecewiseSEM)
theme_set(theme_dag())

dag <- dagify(rich ~ distance + elev + abiotic + age + hetero + firesev + cover,
  firesev ~ elev + age + cover,
  cover ~ age + elev + abiotic ,
  exposure = "cover",
  outcome = "rich"
  )

ggdag(dag)

For this exercise, I want to assume that we are particularly interested in the causal effect of cover on species richness. I have specified this in the dag above already. With the ggdag_paths() command, I can isolate all paths that would create a correlation between cover and richness

ggdag_paths(dag)

Looking at the paths, I can see confounding structures, for example for age, abiotic and elevation. So I should definitely control for them. The function

ggdag_adjustment_set(dag)

helps me by suggesting which confounders I should control for. Note that the function doesn’t suggest to adjust for mediation structures per default, but keeps them in the graph, so you have to decide what to do with them. You can directly ask to include adjustment for mediation if you run

ggdag_adjustment_set(dag, effect="direct")

in this case, plot suggest to adjust for fire severity, to isolate the direct effect of cover on richness.

So, the model we should fit is

fit = lm(rich ~ cover + abiotic + elev + firesev + age, data = keeley)

7.4.1 Table 2 fallacy

When reporting this, note that we have only corrected the relationship rich ~ cover for confounding. Consequently, we should not report the entire regression table above, or at least make a clear distinction about which variables have been corrected, and which haven’t.

The blind reporting of the entire regression table is known as Table 2 fallacy (because regression tables are often Table 2 in a paper).

7.4.2 Structural equation models (SEMs)

But what if we are interested in all the causal relationships? If we have a graph already and are interested in all relationships in it (not just one effect, for which the adjustment-set regression above suffices), a good option is to fit a structural equation model.

Structural equation models (SEMs) are models that are designed to estimate entire causal diagrams. For GLM responses (see Chapter 9), you will currently have to estimate the DAG (directed acyclic graph) piece-wise, e.g. with piecewiseSEM.

For linear (= normally distributed) SEMs, we can estimate the entire DAG in one go. This also allows us to have unobserved variables in the DAG. One of the most popular packages for this is lavaan. The advantage of lavaan is that you can also have unobserved covariates which can be modeled latent.

If you have REs (Chapter 4) or GLM-type dependencies (Chapter 9), the only way to fit everything in one go is to go to use Bayesian Inference, e.g. STAN (for examples, see the chapter on Bayesian causal models in Hartig (2024)). However, what you can do is to fit your models piece-wise. The most popular package for this purpose is piecewiseSEM (see the package documentation for the supported model classes).

Hartig, F. (2024) “Introduction to Bayesian statistics with R.” Available at: https://florianhartig.github.io/LearningBayes/. 
library(piecewiseSEM)

mod = psem(
  lm(rich ~ distance + elev + abiotic + age + hetero + firesev + cover, data = keeley),
  lm(firesev ~ elev + age + cover, data = keeley),

)

The output of summary(mod) has three parts: (1) the d-separation tests, each of which tests one arrow that is missing in the DAG (here 4 tests, none significant); (2) Fisher’s C statistic, which combines these tests: a p-value above 0.05 means that there is no evidence against the DAG, a small p-value would indicate a missing arrow or a wrong structure; (3) the path coefficients of all regressions (use the standardized coefficients to compare the strength of different paths).

7.5 Partialling out confounders (Frisch-Waugh-Lovell)

There is another trick to remove confounders, which is often used in machine learning. Consider the following example, where we have a main effect x->y, and a confounder (see Section 7.3) conf.

conf = runif(500) # confounder
x = 0.5 * conf + 0.5 *runif(500) # main predictor
y = 1.2* x + conf + rnorm(500, sd = 0.2)

A multiple regression identifies the correct effect for x.

summary(lm(y ~ x + conf))

Another way to get those effects is the following, where we fit all variables against the confounder. This essentially conditions on the confounder. If we then regress the residuals without the confounder, we get the original effect. The point estimate equals that of the multiple regression; the standard error of this second stage is not exactly valid, as it ignores that the residuals were estimated.

resX.C = resid(lm(x~conf))
resY.C = resid(lm(y~conf))

summary(lm(resY.C ~ resX.C))

Note

Strictly speaking, what we did here is the classic Frisch-Waugh-Lovell partialling-out result, not yet full double/debiased machine learning as introduced by Chernozhukov et al. (2018). What turns this trick into “double ML” is two additional ingredients: (i) the two nuisance regressions (x ~ conf and y ~ conf) are fit with flexible, potentially high-dimensional ML estimators (e.g. random forests, gradient boosting) instead of a simple lm, and (ii) cross-fitting - the nuisance models are trained on one part of the data and the residuals (and thus the effect of interest) are computed on a held-out part. Cross-fitting is what removes the overfitting bias that flexible ML nuisance models would otherwise introduce into the residuals, and it is what gives double ML its statistical guarantees (valid confidence intervals even when the nuisance functions are estimated nonparametrically).

Chernozhukov, V. et al. (2018) “Double/debiased machine learning for treatment and structural parameters,” The Econometrics Journal, 21(1), pp. C1–C68. Available at: https://doi.org/10.1111/ectj.12097.

7.6 Take-home messages

Tip
  1. Decide before you model whether you want to estimate an effect or to predict. For effects, state the causal question (which predictor, which response), draw the assumed causal graph and choose the variables from it. Randomization removes confounding by design; in observational data, adjustment only works if the graph is right.
  2. Control for confounders (common causes of predictor and response). A variable that merely correlates with both is not necessarily a confounder: the direction of the arrows decides.
  3. Do not control for colliders (variables influenced by both predictor and response): including them creates a spurious association, so do not simply include all available variables.
  4. Mediators depend on the question: leave them out for the total effect, include them for the direct effect, so state which one you target.
  5. Report only the effect of the target predictor. The coefficients of the other variables were adjusted only for the target relationship, not for their own confounders (Table 2 fallacy).

TipSolution
  • Agriculture, Catholic could be seen as confounders or mediators, depending on whether you think Education affects the number of people being in Agriculture or Catholic, or vice versa
  • Infant mortality could be a mediator or a collider, depending on whether you think fertility -> infant mortality or infant mortality -> fertility. I would tend to see it as a mediator.

For all mediators (see Section 7.3): remember that if you want to get the total (indirect + direct) effect of education on fertility, you should not include mediators. If you want to get the direct effect only, they should be included.
