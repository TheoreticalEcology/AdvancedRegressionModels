9.1 Introduction to GLMs

Generalized linear models (GLMs) extend the linear model (LM) to other (i.e. non-normal) distributions. The idea is the following:

  1. We want to keep the regression formula \(y \sim f(x)\) of the lm with all its syntax, including splines (Section 2.5.3), random effects (Chapter 4) and all that. In the GLM world, this is called the “linear predictor”.

  2. However, in the GLM, we now allow other residual distributions than normal, e.g. binomial, Poisson, Gamma, etc.

  3. Some families require a particular range of the predictions (e.g. binomial requires predictions between zero and one). To achieve this, we use a so-called link function to bring the results of the linear predictor to the desired range.

In R, the distribution is specified via the family() function, which distinguishes the glm from the lm function. If you look at the help of family, you will see that the link function is an argument of family(). If no link is provided, the default link for the respective family is chosen.

?family

A full GLM structure is thus:

\[y \sim family[link^{-1}(f(x) + RE)]\]

Note

As you see, I noted the link function as \(link^{-1}\) in this equation. The reason is that traditionally, the link function is applied to the (expected value of the) left hand side of the equation, i.e.

\[link(E[y]) = f(x)\]

This is important to keep in mind when interpreting the names of the link function - the log link, for example, means that \(log(E[y]) = f(x)\), which actually means that we assume \(E[y] = exp(f(x))\), i.e. the result of the linear predictor enters the exponential function, which assures that we have strictly positive predictions.

The function \(f(x)\) itself can have all components that we discussed before, in particular

  • You can add random effects as in Section 4.2.3 (using functions lme4::glmer or glmmTMB::glmmTMB)

  • You can also use splines using mgcv::gam (see Section 2.5.3)

9.2.1 Count data - Poisson regression

The standard model for count data (0, 1, 2, 3, …) is the Poisson regression, which implements

  • A log-link function -> \(y = exp(ax + b)\)

  • A Poisson distribution

As an example, we use the data set birdfeeding from the EcoData package - the dataset consists of observations of food given by parents to nestlings as a function of the attractiveness of the nestling.

Note 9.1: Different definitions of deviance

The term deviance is used with two related, but different definitions, which is a common source of confusion:

  1. Deviance of a GLM (general definition): \(D = 2\,[\log L(\text{saturated}) - \log L(\text{fitted})]\). The saturated model has one parameter per observation and fits the data (almost) perfectly, so \(D\) measures how far the fitted model is from the best possible fit. This is what deviance() returns for glm objects, and what is shown as null and residual deviance in summary() and in the anova() tables of GLMs. For a normal linear model, \(D\) is the residual sum of squares (RSS; divided by \(\sigma^2\) for the scaled deviance), which is why the deviance plays the role of the sum of squares in GLMs (see Section 3.1.1 for the sums of squares in ANOVA). For 0/1 binomial data, \(\log L(\text{saturated}) = 0\), and thus \(D = -2 \log L\).
  2. Deviance as \(-2 \log L\): in many mixed-model contexts, \(-2 \log L(\text{fitted})\) is called the deviance (older versions of lme4 did this in their anova() tables, and deviance() for lmer fits still returns it; newer lme4 versions and glmmTMB print it as -2*log(L)). It is the same as \(D\) without the term \(2 \log L(\text{saturated})\). AIC is built on this quantity, \(\mathrm{AIC} = -2 \log L + 2k\).

The two definitions differ by \(2 \log L(\text{saturated})\), which is the same for all models fitted to the same data. Therefore, differences between models agree for both definitions as long as the dispersion is fixed (e.g. Poisson, binomial), and likelihood ratio tests and AIC comparisons give the same results. The absolute values are different, and numbers calculated with the two definitions must not be compared. For normal linear models, differences in RSS and differences in \(-2 \log L\) are not identical, because the variance is estimated: at the maximum likelihood estimate, \(-2 \log L = n \log(\mathrm{RSS}/n) + n (1 + \log 2\pi)\).

Note

The deviance of our model M1 is defined as \(Deviance_{M_1} = 2 \cdot (logL(M_{saturated}) - logL(M_1))\)

Calculation of Pseudo-R2 with deviance or logL

Common pseudo-R2 such as McFadden or Nagelkerke use the logL instead of the deviance, whereas the deviance-based pseudo-R2 (1 - Dres/Dnull, the “proportion of deviance explained”) uses the deviance. However, R2 calculated based on deviance or logL differs considerably, as the former is calculated in reference to the maximal achievable fit (saturated model) while the latter just compares the improvement of fit compared to the null model:

# Based on logL
McFadden = 1-(logLik(fit1))/(logLik(fitNull))
print(McFadden)
'log Lik.' 0.06314239 (df=2)
# Based on deviance
R2_dev = 1- (logLik(fitSat) - logLik(fit1)) / (logLik(fitSat) - logLik(fitNull))
print(R2_dev)
'log Lik.' 0.2907272 (df=25)

Note: outside of the context of GL(M)Ms, deviance is sometimes defined simply as \(-2 \log L(M_1)\) (see Note 9.1 for the two definitions).

9.2.1.1 Notes on the Poisson regression

Poisson vs. log transformed count data: For count data, even if the distribution is switched, the log link is nearly always the appropriate link function. Before GLMs were widely available, it was common to fit an lm to log-transformed counts (log(y + 1) if there are zeros). This is similar to, but not the same as, a Poisson GLM with log link: the lm assumes a constant variance on the log scale, the Poisson GLM a variance equal to the mean (see also Section 9.2.3).

Log offset: If there is a variable that controls the number of counts (e.g. time, area), this variable is usually added as an offset in the following form

fit = glm(y ~ x + offset(log(area)), family = "poisson")

As the log-link connects the linear predictor as in \(y = exp(x)\), and \(exp(x + log(area)) = exp(x) \cdot area\), this makes the expected counts proportional to area, or whatever variable is added as a log offset.

Interactions: As for all GLMs with nonlinear link functions, interpretation of the interactions is more complicated. See the section on interactions in GLMs (Section 9.4) for notes on this.

Caution 9.1: Before testing a GLM
  • Check dispersion first. For Poisson and k/n binomial models, overdispersion (see the section on dispersion problems, Section 9.3.2) makes all p-values of car::Anova() and summary() too small. It is not unusual that a seemingly highly significant effect disappears once the dispersion is accounted for. If you use a quasi-family (see Section 9.3.2) as a quick fix, use car::Anova(m, test = "F").
  • Coding and centering. Everything that was said in the chapter on ANOVA (Chapter 3) about type II vs. III (Section 3.2.3), contrasts (Section 3.2.4) and centering also applies to GLMs, with the difference that averages are taken on the link scale.
  • Reporting on the response scale. emmeans() works for GLMs as well. With type = "response", means are back-transformed to the response scale. Comparisons with pairs() are then reported as ratios (Poisson, log link) or odds ratios (binomial, logit link), while the tests are still performed on the link scale.
  • Mixed models. For tests and confidence intervals of GLMMs fitted with glmer or glmmTMB, see the overview in Table 4.1.

Of course, when using car::Anova with random effects, the caveats that we discussed in the section on degrees of freedom of random effects (Section 4.5.1) apply: it does not account for changes in the degrees of freedom created by changing the fixed effect structure. Something like the lmerTest package which uses a df approximation does not exist for GLMMs. Thus, the values that you obtain here are calculated under the assumption that the RE structure is the same.

If you see large changes in your RE structure, or if you want to select on the REs, you can move to a simulated LRT (see Section 4.5.3.3).

9.2.2.1 Notes on the logistic regression

Offset: for 0/1 data with different exposure times t, as in survival analysis, a binomial GLM with cloglog link and offset(log(t)) models a constant hazard exactly (P(event) = 1 - exp(-lambda t)). The logit link has no such interpretation.

Interactions: As for all GLMs with nonlinear link functions, interpretation of the interactions is more complicated. See the section on interactions in GLMs (Section 9.4) for notes on this.

Overdispersion: 0/1 binomial responses cannot be overdispersed, but k/n responses can be. However, 0/1 responses can show overdispersion if grouped to k/n. Note the section on residual checks (Section 9.3), in particular the dispersion problems (Section 9.3.2), as well as comments on testing binomial GLMs in the
DHARMa vignette.

More than two categories: if the response is one of several unordered categories (e.g. land-use type, type of food chosen), the logistic regression generalizes to the multinomial logistic regression (nnet::multinom; with random effects, brms with family categorical). It estimates one set of coefficients for each category, as log odds ratios relative to a reference category. The response can be one category per observation or the counts per category for each unit (e.g. number of food items of each type). If the categories are ordered (e.g. damage classes, Likert scales), use a cumulative link model (ordinal::clm, or clmm with random effects), which assumes that each predictor has the same effect on all thresholds between categories (check with ordinal::nominal_test()). If several categories can apply at the same time, the response is not multinomial, but several binary responses (see the multivariate GLMs, Section 11.6). Variants exist for choices with alternative-specific predictors (mlogit) and for matched case-control designs (survival::clogit).

9.2.3 Continuous positive response - Gamma regression

The Gamma regression is the natural choice for a strictly positive, continuous, right-skewed response whose variance grows with the mean (e.g. concentrations, waiting times, biomass, body sizes). 9.2.4 Continuous proportions: beta regression and alternatives

We already covered discrete proportions (k successes out of n trials), which can be modeled with a logistic regression (Section 9.2.2). Many proportions, however, are continuous: a fraction of an area, a concentration, a share of time spent in an activity. For these, there is no number of trials, so the binomial does not apply.

Before choosing a model, check how the proportion was measured:

  • Counts out of a known total (e.g. germinated seeds out of seeds sown) are k/n data: use a binomial GLM, or a beta-binomial (family = betabinomial in glmmTMB) if they are overdispersed (Douma and Weedon, 2019).
  • Ordered classes (e.g. 0-5%, 5-25%, 25-50%, …) are ordinal data (see the notes on the logistic regression, Section 9.2.2.1). Analyzing class midpoints as if they were measured values ignores how coarse the classes are.
  • Continuous values are the topic of this section.

For continuous proportions, there are several reasonable options. The most common are presented in the following table:

The logit transform is a quick fix. The standard distribution for continuous proportions, however, is the beta distribution. It is bounded between 0 and 1 and has two parameters: the mean and the precision \(\phi\). A large \(\phi\) means that values scatter little around the mean. glmmTMB prints \(\phi\) as “Dispersion parameter”, which is confusing: for the beta, a large value means a narrow distribution. Like the binomial, the beta is naturally heteroskedastic: its variance is largest for a mean of 0.5 and shrinks towards 0 and 1. As in the logistic regression, the mean is modeled with a logit link, so coefficients are on the logit scale.

Dealing with 0/1 observations: The beta distribution is defined only strictly between 0 and 1, so exact zeros or ones need an extension. The hurdle beta (in glmmTMB: zero-inflated beta) works like zero-inflation for counts (Section 9.3.3), but because a beta never produces an exact 0, the zero part is a separate logistic model for the zeros. A predictor can therefore affect whether a value is zero and how large it is otherwise in different ways (Douma and Weedon, 2019). The ordered beta (Kubinec, 2023) uses a single linear predictor plus two thresholds on the logit scale that decide when a value is exactly 0 or 1. It assumes that a predictor that raises the mean of the continuous part also lowers the probability of a 0, and it needs fewer parameters when there are several predictors. The ordered beta was introduced only in 2022, so applied studies more often use zero/one-inflated or hurdle models. Other options are to squeeze the data into (0, 1) before a beta regression (Smithson and Verkuilen, 2006), a quasibinomial GLM (no likelihood, so no AIC and no DHARMa residuals), or quantile regression (Section 10.3.2). The beta models in glmmTMB (beta, ordered beta, hurdle beta) can include random effects, and their precision can depend on predictors (dispformula, Section 10.1.2). An example with zeros follows in the case study on plant cover (Section 9.7.2).

9.2.4.1 Several proportions from the same unit

If you analyze several proportions measured on the same unit (e.g. cover of several plant species in a plot, the time an animal spends on different activities, land-use shares of a region), their residuals are usually correlated, for example because they share unmeasured conditions of that unit. Separate models are fine for questions about one response at a time, but comparisons or sums across responses need a joint model (Section 11.6). If the proportions are shares of a whole that sum to exactly 1 (e.g. diet composition), Dirichlet regression respects this constraint (e.g. brms family dirichlet). The Dirichlet does not allow exact zeros: zeros must be squeezed into (0, 1) or modeled with a zero-augmented Dirichlet; if the shares come from counts (e.g. number of food items), use a multinomial model instead (Douma and Weedon, 2019).

Douma, J.C. and Weedon, J.T. (2019) “Analysing continuous proportions in ecology and evolution: A practical introduction to beta and dirichlet regression,” Methods in Ecology and Evolution, 10(9), pp. 1412–1430. Available at: https://doi.org/10.1111/2041-210X.13234.

9.3.2 Dispersion problems in GLMs

One thing that is different between GLMs and LM is that GLMs can display overall dispersion problems. The most common GLMs to show overdispersion are the Poisson and the binomial with k/n data (0/1 data cannot be overdispersed).

The reason is that simple GLM distributions such as the Poisson or the Binomial (for k/n data) do not have a parameter for adjusting the spread of the observed data around the regression line (dispersion), but their variance is a fixed function of the mean.

There are good reasons for why this is the case (Poisson and Binomial describe particular processes, e.g. coin flip, for which the variance is a fixed function of the mean), but the fact is that when applying these GLMs on real data, we often find overdispersion (more dispersion than expected), and more rarely, underdispersion (less dispersion than expected).

To remove the assumptions of a fixed dispersion, there are three options, of which I usually prefer the third one:

  1. Quasi-distributions, which are available in glm. Those add a term to the likelihood that corrects the p-values for the dispersion, but they are not distributions, so there are no residual checks and no AIC. Therefore discouraged.
  2. Observation-level random effect (OLRE) - Add a separate random effect per observation. This effectively creates a normal random variate at the level of the linear predictor, increases variance on the responses.
  3. A GLM distribution with variable dispersion, for Poisson usually the negative binomial, for k/n binomial data the beta-binomial (family = betabinomial in glmmTMB).

The reason why I prefer the 3rd option is that it allows better residual checks and to model the dispersion as a function of the predictors (see Section 10.2). OLRE is also a valid solution.

Note

Overdispersion is often created by model misfit. Thus, before moving to a variable dispersion GLM, you should check for / correct model misfit.

9.3.3 Zero-inflation

Another common problem in count data (Poisson / negative binomial), but also other GLMs (e.g. binomial, beta) is that the observed data has more zeros than expected by the fitted distribution. For the beta, 1-inflation, and for the k/n binomial, n-inflation is also common, and tested for / addressed in the same way.

To deal with this zero-inflation, one usually adds an additional model component that controls how many zeros are produced. The default way to do this is assuming two separate processes which act after one another:

  1. First, we have the normal GLM, predicting what values we would expect
  2. On top of that, we have a logistic regression, which decides whether the GLM prediction or a zero should be observed

Note that the result of 1 can also be zero, so there are two explanations for a zero in the data. Zero-inflated GLMMs can, for example, be fit with glmmTMB, using the ziformula argument.

9.3.3.1 Recognizing zero-inflation

Caution

The fact that you have a lot of zeros in your data does not indicate zero-inflation. Zero-inflation is with respect to the fitted model. You can only check for zero-inflation after fitting a model.

Let’s look at our last model - DHARMa has a special function to check for zero-inflation

  2. When there is really zero-inflation, variable dispersion models such as the negative Binomial often simply increase the dispersion to account for the zeros, leading to no apparent zero-inflation in the residuals, but rather underdispersion.

It looks in the effect plots as if the slope is changing as well, but note that this is because the effect plots scale the y axis according to the link - absolutely, the effect of concentration is 10% for both groups.

The reason is simple: if we plot the plogis function, it becomes obvious that at different base levels (which would be controlled by trt in our case), moving a unit in concentration has a different effect.

If we turn this around, this means that if we want the model to have the same effect of concentration at the response scale for both treatments, we must implement an interaction.

Whether this is a feature or a bug of GLMs depends a bit on the viewpoint. One could argue that, looking at survival, for example, it doesn’t make sense that the concentration should have an effect of absolute 10% on top of the baseline created by trt for either 45% and 90% survival, and if we see such an effect, we should interpret this as an interaction, because on the odds scale, which is what the logit link works with, the same 10% change is much larger close to 100% than around 50%. Whether this is the biologically relevant scale is a modeling decision.

Still, this also means that main effects and interactions can change if you change the link function, and default links are not always natural from a biological viewpoint.

9.5 New considerations for GLMMs

As we saw, in principle, random effects can be added to GLMs very much in the same way as before (Chapter 4). Note, however, that there is a conceptual difference:

  1. In an LMM, we had y = f(x) + RE + residual, where both RE and residual error were normal distributions

  2. In a GLMM, we have \(y \sim dist[link^{-1}(f(x) + RE)]\), so the normally distributed RE goes through the inverse link into the response distribution

This has a number of consequences that may be unexpected if you don’t think about it.

9.5.1 Unconditional vs. marginal predictions

One of those is that, if you have a nonlinear link function, predictions based on the fixed effects (unconditional, see Tip 4.3 for the terms) will not correspond to the mean of your data, or the average of the model predictions including the random effect (marginal predictions). To understand this, imagine we have a logistic regression, and our fixed effects predict a mean of 1. Then the unconditional prediction at the response scale

plogis(1)
[1] 0.7310586

Now, let’s try to see what the average (marginal) prediction over all random effects is. We simulate random intercepts from a normal distribution with sd = 1 (1e5 draws). In this case, there will be additional variation around the random intercept.

mean(plogis(1 + rnorm(1e5, sd = 1)))
[1] 0.6972359

The value (about 0.70) is lower than the unconditional prediction (0.73), and this value is also what you would approximately get if you take the mean of your data.

Whether this is a problem or not is a matter of perspective. From statistical viewpoint, assuming that your model assumptions correspond to the data-generating model, there is nothing wrong with the unconditional (fixed effect) prediction not corresponding to the mean of the data. From a practical side, however, many people are unsatisfied with this, because they want to show predictions against data. A simple and transparent way to create marginal predictions is the simulation above: create unconditional predictions on the link scale, add random effects simulated with the estimated variances, push them through the corresponding link function and average.

9.6 Take-home messages

Tip
  1. Choose the distribution from the type of response data (counts, 0/1, k/n, positive continuous, proportions), and then check the residuals of the fitted model.
  2. The estimates are on the scale of the link function. Report effects on the response scale: rate ratios for log links, odds ratios for logit links, or back-transformed predictions with CIs (emmeans(..., type = "response")).
  3. Check dispersion before you interpret p-values: with overdispersed Poisson or k/n binomial data, p-values are too small. Overdispersion is often caused by model misfit, so check the model structure first; then use a negative binomial or beta-binomial family, an observation-level random effect, or a dispersion model.
  4. Many zeros do not mean zero-inflation; zero-inflation is relative to the fitted model. Compare models with and without ziformula instead of relying on the residual test alone.
  5. With a nonlinear link, interactions and effects depend on the scale. In a GLMM, predictions from the fixed effects alone (unconditional) need not match the average prediction over the random effects (marginal) or the mean of your data.

9.7.2 Continuous proportions - plant cover

Plant cover is one of the most common continuous proportions in ecology, and it comes with some special issues (Damgaard and Irvine, 2019):

Damgaard, C.F. and Irvine, K.M. (2019) “Using the beta distribution to analyse plant cover data,” Journal of Ecology, 107(6), pp. 2747–2759. Available at: https://doi.org/10.1111/1365-2745.13200.
  • How was cover measured? Pin-point (point-intercept) data are hits out of N pins, i.e. k/n data; as plants grow in clumps, they are often overdispersed (beta-binomial). Cover classes (Braun-Blanquet, Londo, …) are ordinal. Visual estimates in % are continuous, but often rounded to 1, 5 or 10%.
  • Zeros: if a zero means “too little to be recorded”, the ordered beta fits the idea of one continuous scale; if it means that the species cannot grow there, the hurdle beta separates presence from cover where present.
  • Totals: because plants overlap and there is bare ground, the cover of all species in a plot does not sum to 100%. Only relative cover (share of total vegetation) sums to 1.
  • Several species: the cover of species in the same plot is usually correlated (Section 9.2.4.1). For joint models of many species, Korhonen et al. (2024) found the hurdle beta most accurate in simulations, with no noticeable difference to ordered beta for real data.
Korhonen, P. et al. (2024) “A comparison of joint species distribution models for percent cover data,” Methods in Ecology and Evolution, 15(12), pp. 2359–2372. Available at: https://doi.org/10.1111/2041-210X.14437.

TipExpected values for the ordered beta

The ordered beta has a linear predictor \(\eta\) and two thresholds \(\psi_1 < \psi_2\) (stored as psi). The probability of an exact 0 is \(1 - \text{logit}^{-1}(\eta - \psi_1)\), of an exact 1 it is \(\text{logit}^{-1}(\eta - \psi_2)\), and in between the values follow a beta with mean \(\text{logit}^{-1}(\eta)\). The expected value combines the three parts:

ordbeta_mean <- function(m, newdata) {
  eta <- predict(m, newdata = newdata, type = "link", re.form = NA)
  psi <- m$fit$par[names(m$fit$par) == "psi"]   # the two thresholds
  p0 <- 1 - plogis(eta - psi[1])                  # P(y = 0)
  p1 <- plogis(eta - psi[2])                      # P(y = 1)
  p1 + (1 - p0 - p1) * plogis(eta)
}

re.form = NA sets random effects to zero, so the function also works for mixed models. If the data contain no 1s, the upper threshold cannot be estimated well and gets a very large value (here about 19), which does no harm.

9.7.4 Making spatial predictions with a logistic regression - elephant SDM

To demonstrate how to fit a species distribution model and extrapolate it in space, let’s have a look at the elephant dataset, which is contained in EcoData

library(EcoData)
?elephant

The object elephant contains two subdatasets

  1. elephant$occurenceData contains presence / absence data as well as bioclim variables (environmental predictors) for the African elephant

  2. elephant$predictionData data with environmental predictors for spatial predictions

The environmental data consists of 19 environmental variables, called bio1 through bio19, which are public and globally available bioclimatic variables (see https://www.worldclim.org/data/bioclim.html for a description of the variables). For example, bio1 is the mean annual temperature. No understanding of these variables is required for the task, the only difficulty is that many of them are highly correlated because they encode similar information (e.g. there are several temperature variables).

The goal of this exercise is to fit a logistic regression model based on the observed presence / absences, and then make new predictions of habitat suitability in space across Africa based on the fitted model. Thus, our workflow consists of two steps:

  1. building and optimizing the predictive model, and
  2. using the predictive model to make predictions on new data and visualizing the results.

Here an example of how you could do this

Build predictive model:

model = glm(Presence~bio1, data = elephant$occurenceData, family = binomial()) # minimum model

To check the predictive power of the model, you can either use

AIC(model) 
[1] 3511.176
library(pROC)
auc(elephant$occurenceData$Presence, predict(model, type = "response"))
Area under the curve: 0.7053

The AUC is a common measure of how well a model separates presences from absences: the probability that a randomly chosen presence gets a higher predicted value than a randomly chosen absence (0.5 = random, 1 = perfect). However, it doesn’t penalize for complexity, as the AIC. Better to look at it under cross-validation (Section 8.4)

library(boot)
res = cv.glm(elephant$occurenceData, model, cost = auc, K=5)
res$delta
[1] 0.7054131 0.7054131

Currently, fit and validation AUC are nearly identical, because we have a very simple model. However, for more complex models, this could change.

  • Drop some of the highly correlated variables (don’t use all of them).

  • Use quadratic effects

  • Use stepAIC or the dredge function (Tip 8.2) to optimize the predictive model

Make new predictions

The data for making spatial predictions is in elephant$predictionData. This new dataset is not a data.frame but a raster object, which is a special data class for spatial data. You can plot one of the predictors in the following way.
