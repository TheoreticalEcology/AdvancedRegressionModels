4.1 Motivation

Random effects are a very common addition to regression models that are used to account for grouping (categorical) variables such as subject, year, location. To explain the motivation for these models, as well as the basic syntax, we will use an example data set containing exam scores of 4,059 students from 65 schools in Inner London. This data set is located in the R package mlmRev.

  • Response: “normexam” (Normalized exam score).
  • Predictor 1: “standLRT” (Standardized LR test score; Reading test taken when they were 11 years old).
  • Predictor 2: “sex” of the student (F / M).
  • Grouping factor: school

If we analyze this with a simple LM, we see that reading ability and sex have the expected effects on the exam score.

library(mlmRev)
library(effects)

mod0 = lm(normexam ~ standLRT + sex , data = Exam)
plot(allEffects(mod0))

However, it is reasonable to assume that not all schools are equally good, which has two possible consequences:

  • If school identity correlates with sex or standLRT, school could be a confounder (see Section 4.4.4 for a check, and the chapter on causal inference, Chapter 7)
  • Residuals will be correlated within schools, thus they are not iid (pseudo-replication)

We could solve this problem by fitting a different mean per school

mod0b = lm(normexam ~ standLRT + sex + school , data = Exam)

however, with 65 schools this would cost 64 degrees of freedom, which is a high cost just for correcting the possibility of confounding and a minor residual problem.

The solution: Mixed / random effect models. In a mixed model, we assume (differently to a fixed effect model) that the variance between schools originates from a normal distribution. There are different interpretations of a random effect (more on this in Section 4.3.1), but one interpretation is to view the random effect as an additional error, so that such a mixed model has two levels of error:

  • First, the random effect, which is a normal “error” acting on an entire group of data points (in this case school).

  • And second, the residual error, which is a normal error per observation and acts on top of the random effect

Because of this hierarchical structure, these models are also called “multi-level models” or “hierarchical models”.

Note

Because grouping naturally occurs in any type of experimental data (batches, blocks, observer, subject etc.), random and mixed effect models are the de-facto default for most experimental data! Naming conventions:

  • No random effect = fixed effect model
  • Only random effects = random effect model
  • Random effects + fixed effects = mixed model

Most models that are used in practice are mixed models

4.2 Specifying and estimating mixed models

4.2.1 The random intercept model

The simplest random effect structure is the random intercept model.

Each random effect model has a fixed counterpart. For the random intercept model, this counterpart is the model we already saw in Section 4.1, with school as a fixed effect

mod0b = lm(normexam ~ standLRT + sex + school , data = Exam)

The random intercept model is practically identical to the model above, except that it assumes that the school effects come from a common normal distribution. The model can be estimated with lme4::lmer

library(lme4)
mod1 = lmer(normexam ~ standLRT + sex +  (1 | school), data = Exam)
summary(mod1)

If we look at the outputs, you will probably note that the summary() function doesn’t return p-values. More on this in Section 4.5.1. Also, we see that the effects of the individual school are not explicitly mentioned. The summary only returns the mean effects over all schools, and the variance between schools (Random effects block: the school sd of 0.30 compares with the residual sd of 0.75, i.e. school accounts for about 14% of the variance that the fixed effects do not explain, the intraclass correlation). However, you can obtain the individual school effects via

ranef(mod1)

Moreover, unlike the outputs we have seen before, the model also returns a correlation between fixed effect estimates. This, however, is simply a choice of the programmers, it has nothing to do with the random effect models - you could calculate the same output for the lm() via the function vcov().

Here is a visualization of the fitted effects for standLRT

We can see that there is the same slope, but a different intercept per school.

The RE effectively “centers” the categorical predictor - unlike for the fixed effect model, where the intercept would be interpreted as the value for the first school, the intercept in the random effect model is the mean across all schools, and the REs measure the deviation of the individual school from the mean. It should be stressed, however, that this is a welcome consequence, but not the main motivation, for the RE structure.

Tip 4.1: From study design to random effects

The random effect structure should follow from the design of the study, not from the data. Ask yourself:

  • What is the experimental unit, i.e. the unit to which a treatment was applied, or at which a predictor varies? If you have several measurements per unit (several plants per plot, several visits per site), these measurements are not independent replicates. Treating them as if they were is called pseudoreplication (Hurlbert, 1984) and makes p-values too small. A random intercept for the unit (here (1|plot)) accounts for this when the treatment varies between units: the effective sample size is then roughly the number of plots, not the number of plants. The same applies to any predictor that is constant within a unit, e.g. the elevation of a site that was surveyed repeatedly.
  • How are the units grouped? Typical designs and their random effects:
    • randomized blocks: y ~ treatment + (1|block)
    • several measurements per plot (subsampling): y ~ treatment + (1|plot)
    • split-plot (factor A on main plots, factor B on subplots within the main plots): y ~ A * B + (1|block/mainplot) (/ means nested: main plots within blocks, see Tip 4.2)
    • repeated measurements of the same units over time: y ~ treatment * time + (1|site), possibly with a temporal correlation structure (Section 11.2)
    • two independent grouping factors, e.g. sites and observers: y ~ x + (1|site) + (1|observer) (crossed random effects, Tip 4.2)
  • Does the grouping factor have enough levels? The variance of a random effect is estimated from its levels. A common rule of thumb is therefore that a random effect needs at least about 5-10 levels, and that a grouping variable with fewer levels is better modeled as a fixed effect (Bolker, 2015; Harrison et al., 2018). The discussion is, however, nuanced (see Section 4.3.3): with few levels, singular fits (variance estimated as zero) are common, but simulations suggest that the tests of the population-level effects can still be reliable (Oberpriller, Souza Leite and Pichler, 2022).
  • Is there structure left after that? Correlation within units over time (Section 11.2) or changing variance (Chapter 10) can be modeled in addition. The college student case study (Section 4.7.2) shows a worked example.
Hurlbert, S.H. (1984) “Pseudoreplication and the design of ecological field experiments,” Ecological Monographs, 54(2), pp. 187–211. Available at: https://doi.org/10.2307/1942661.

4.2.2 The random slope model

A second effect that we could imagine is that the effect of standLRT is different for each school. As a fixed effect model, we would express this, for example, as lm(normexam ~ standLRT*school + sex)

The random effect equivalent is called the random slope model. A random slope model assumes that each school also gets their own slope for a given parameter (per default we will always estimate slope and intercept, but you could overwrite this, not recommended!). Let’s do this for standLRT (you could of course fit random slopes on both predictors as well).

mod2 = lmer(normexam ~ standLRT + sex +  (standLRT | school), data = Exam)

The result is similar to the random intercept model, except that we have an additional variance term for the slopes, and a correlation between random intercepts and random slopes (Corr in the output).

4.2.3 Mixed models in different packages

4.2.3.1 lme4 / glmmTMB

There are a large number of packages to fit mixed models in R. The main packages that you use, because they are most user-friendly and stable, are lme4 and glmmTMB. They share more or less the same syntax for random effects.

  • Random intercept: (1 | group).
  • ONLY random slope for a given fixed effect: (0 + fixedEffect | group).
  • Random slope + intercept + correlation (default): (fixedEffect | group).
  • Random slope + intercept without correlation: (fixedEffect || group), identical to
    (1 | group) + (0 + fixedEffect | group) (for a numeric fixedEffect; for a factor, lme4 still estimates the correlations between its levels).
  • Nested random effects: (1 | group / subgroup). If groups are labeled A, B, C, … and subgroups 1, 2, 3, …, this will create labels A1, A2 ,B1, B2, so that you effectively group in subgroups. Useful for the many experimental people that do not label subgroups uniquely, but otherwise no statistical difference to a normal (crossed) random effect.
  • Crossed random effects: You can add random effects independently, as in
    (1 | group1) + (1 | group2).
Tip 4.2: More on crossed vs. nested REs

There is often confusion about the behavior and meaning of crossed vs. nested REs. From the statistical / mathematical side, there is no difference between them, there are just REs. Crossed vs. nested is a shorthand to tell you how the data was coded.

Let’s look at the Exam data, for example. If you run

table(Exam$student, Exam$school)

you will see that the student ID = 1 appears in many schools. Clearly, this cannot be the same student, the reason is that each school uses their own ID. If you would fit a crossed RE, as in

m1 = lmer(normexam ~ standLRT + sex +  (1 | school) + (1 |student), data = Exam)
summary(m1)

you would fit a common effect for each student with ID = 1. This, however, doesn’t make sense, there is no connection between these students. Thus, you should fit

m2 = lmer(normexam ~ standLRT + sex +  (1 | school/student), data = Exam)
summary(m2)

Compare the number of RE groups in the summary: in m1, you have 650 students. In m2, you have 4055 student:school levels for the RE. Thus, the nested syntax makes sure that students with the same ID in different schools are treated as different individuals.

You could fit the same mod by changing the coding of student. To do this, we create a new variable, combining school and student into a unique ID

Exam$uniqueStudent = as.factor(paste(Exam$school, "-", Exam$student))

m3 = lmer(normexam ~ standLRT + sex +  (1 | school) + (1|uniqueStudent), data = Exam)
summary(m3)

If you check the summary of m3, now we also have 4055 levels for uniqueStudent, and the results are identical to the nested model version.

Caution: in the Exam data, almost every student appears only once (4055 student:school levels for 4059 observations), so a student-level RE cannot be separated from the residual error; the fit is singular (sd of student:school = 0). The example only illustrates the coding. Nested REs make sense if the lower level is replicated.

4.2.3.2 nlme

nlme is a classic package for fitting (nonlinear) mixed effect models. I would argue that it is largely superseded by lme4 and glmmTMB, but it still offers a few special tricks that are not available in either lme4 or glmmTMB. A linear mixed model with random intercept in nlme looks like this

nlme::lme(Resp ~ Predictor, random = ~1|Group, data = data)

4.2.3.3 mgcv

If you want to use GAMs, there is basically only mgcv (or brms, if you’re willing to go Bayesian).

# Group must be a factor
mgcv::gam(Resp ~ Predictor + s(Group, bs = 're'), data = data)

4.2.3.4 brms

brms is a very interesting package that allows you to estimate mixed models via Bayesian Inference with STAN.

brm_mod <- brms::brm(Resp ~ Predictor + (1|Group),
                     data = data) # add e.g. family = poisson for GLMMs, see the chapter on GLMs
summary(brm_mod)

A complete brms GLMM is shown in the owls exercise (Caution 9.2). For an introduction to Bayesian mixed models, see the chapter on linear and linear mixed models in Hartig (2024).

4.2.4 REML vs. MLE

Frequentist linear mixed models are usually estimated with REML = restricted maximum likelihood, rather than with classical MLE. Most packages allow you to switch between REML and MLE. The motivation for REML is that for limited data (non-asymptotics), the MLE for variance components of the model are typically negatively biased, because the uncertainty of the fixed effects is not properly accounted for. If you go through the mathematics, you can make an analogy to the bias-corrected sampling variance (Bates, 2011).

Bates, D. (2011) “Computational methods for mixed models,” Vignette for lme4 [Preprint].

REML maximizes the likelihood of linear combinations of the data that do not depend on the fixed effects (equivalently, the likelihood after integrating out the fixed effects). This accounts for the df used by the fixed effects, like dividing by n-p instead of n when estimating a variance in a linear model.

Most packages offer an option to switch between REML and ML estimation of the model. In lme4, this is done via

m = lmer(normexam ~ standLRT + sex +  (1 | school), data = Exam)
m = lmer(normexam ~ standLRT + sex +  (1 | school), data = Exam, REML = F)

Regarding when to use what, use the following rule of thumb:

  • Per default, use REML

  • Switch to ML (REML = FALSE) if you compare models with different fixed effects, or a mixed model with a model without random effects, via LRTs or AIC. For comparing RE structures with identical fixed effects, REML is fine.

Tip

Later in this chapter (Section 4.5.3), we will talk about model selection via LRTs and AIC. Because those depend on the likelihood, it is generally recommended to switch from REML to ML in this case. The reason is that the REML likelihood refers to linear combinations of the data that do not depend on the fixed effects, i.e. to different data when the fixed-effect structure changes, so REML likelihoods are not comparable between models with different fixed effects. I would recommend sticking to this, although I have to say that I have always wondered how big this problem is, compared to the other df problems associated to mixed models (see Section 4.5.1).

4.3 Advantages and interpretation of random effects

What do the random effects mean, and why should we use them?

4.3.1 Interpretation

The classical interpretation of the random intercept is that they model a group-structured residual error, i.e. they are like residuals, but for an entire group. However, this view breaks down a bit for a random slope model.

Another view this is that REs terms absorb group-structured variation in model parameters. This view works for random intercept and slope models. So, our main model fits the grand mean, and the RE models variation in the parameters, which is assumed to be normally distributed.

A third view of RE models is that they are regularized fixed effect models. What does that mean? Note again that, conceptually, every random effect model corresponds to a fixed effect model. For a random intercept model, this would be

lmer(y ~ x + (1|group)) => lm(y ~ x + group)

and for the random slope, it would be

lmer(y ~ x + (x|group)) => lm(y ~ x * group)

So, alternatively to a mixed model, we could always fit a fixed effect model, and that would also take care of the variation in groups. Of course, the output of the two models differs, but that’s just what people programmed. The real difference, however, is that by making the assumption that the random effects come from a normal distribution, we are imposing a constraint on the estimates, which creates a shrinkage on the fitted REs (see Section 4.3.2).

4.3.2 RE shrinkage

To understand shrinkage, note that whatever the fitted sd of the normal distribution underlying the RE, as long as it is finite, it will always be more likely that the RE estimate is at zero (i.e. the grand mean) than at 1 or 2 sd. This means that RE estimates are biased towards the grand mean.

We can visualize the effect by comparing estimates of a fixed to a random effect model

mf = lm(normexam ~ 0 + school, data = Exam)
mr = lmer(normexam ~ (1 | school), data = Exam)

ef = coef(mf)
er = ranef(mr)$school$`(Intercept)`
plot(ef, er, xlab = "fixed", ylab = "random")
abline(0,1)

The plot shows that random effect estimates are biased towards the grand mean, i.e. positive values are lower than in the LM, and negative values are higher than in the LM. This is called shrinkage.

Note

The shrinkage imposed by the RE is equivalent to an L2 (ridge) regression (see Section 8.2.3), or a normally distributed Bayesian prior. You can see this by considering that the log likelihood of a normal distribution is equivalent to a quadratic penalty for deviations from the mean. The difference is that the strength of the penalty, controlled by the RE sd, is estimated. For that reason, the RE shrinkage is also referred to as an example of “adaptive shrinkage”.

This RE shrinkage is useful in many situations, beyond describing a group-structured error in the data. A common use is that by using a random slope model, parameter estimates for groups with few data points are drawn towards the grand mean and thus informed by the estimates of the other groups. For example, if we have data for common and rare species, and we are interested in the density dependence of the species, we could fit a random slope for density per species. Consider the plantHeight case study we did in the exercise in the chapter on linear regression (Caution 2.2). We saw that, even after re-leveling the predictor, not all interactions could be estimated, because some factor levels had only one observation.

library(EcoData)
plantHeight$growthform2 = relevel(as.factor(plantHeight$growthform), "Herb")
plantHeight$sTemp = scale(plantHeight$temp)
fit <- lm(loght ~ sTemp * growthform2 , data = plantHeight)
summary(fit)

If you run the same thing as a random slope model, you will see that we can estimate a random intercept and slope for each growth form, even those that have only one observation

fit <- lmer(loght ~ sTemp + (sTemp | growthform2) , data = plantHeight)
ranef(fit)
$growthform2
           (Intercept)       sTemp

Fern       -0.07771756  0.01484118
Herb/Shrub -0.18519919  0.03351554

The reason is that rare growth forms will be constrained by the RE, while common growth forms with a lot of data can overrule the normal distribution imposed by the random slope and get their own estimate. In this picture, the random effect imposes an adaptive shrinkage, similar to a ridge shrinkage estimator, with the shrinkage strength controlled by the standard deviation of the random effect. An alternative view is that the RE variance acts as a prior distribution on the slope. Of course, the estimates are biased towards the grand mean, so if you want to interpret these estimates that is a cost that you have to take into account.

4.3.3 When to use what?

So, to finalize this discussion: there are essentially two main differences between a random vs. fixed effect model

  1. In the RE model, we are fitting a grand mean and differences from the grand mean, while in the fixed effect model, we have to set up contrasts (various options, see Section 2.6.1), with treatment contrasts as defaults
  2. The LM (OLS) is mathematically proven to be the best linear unbiased estimator (BLUE) of the regression problem. In a mixed model, REs (but not fixed effects) are biased towards the grand mean, but the advantage is that the random effect loses fewer degrees of freedom, i.e. the power on the fixed effects will be higher.

While point 1 is more a choice about how to report results (in principle, we could also calculate the grand mean for fixed effect group estimates), the second point (higher power) is a clear advantage in many cases, in particular if you don’t care about the bias on the REs. Therefore, the rule of thumb for REs is:

  • If you have a categorical variable, and you’re not interested in its estimates, model it as a RE

  • If you want to get unbiased estimates of the categorical variable (or its interactions), use a fixed effect

A common question is how many levels a grouping variable needs to be modeled as a random effect. Because the variance of a random effect is estimated from its levels, a common rule of thumb is to use at least about 5-10 levels, and to model a grouping variable with fewer levels as a fixed effect (Bolker, 2015; Harrison et al., 2018). With few levels, the variance estimate is indeed imprecise and biased towards zero, and singular fits are common. However, if you are interested in the population-level effect of a predictor rather than in the individual levels, simulations by Oberpriller, Souza Leite and Pichler (2022) suggest that a mixed model can still give reliable tests, provided that singular fits are handled. They recommend to start with a mixed model regardless of the number of levels. If the effect of the predictor varies between groups, start with a correlated random slope and intercept; after a singular fit, remove the correlation (||, see Section 4.4.1), and if the fit is still singular, switch to a fixed effect. In their simulations, singular mixed models had inflated type I error rates, similar to a model that omits the grouping variable, and omitting random slopes that are present in the data also inflated the type I error. In short, with few levels both options can be defended, and more levels are clearly better, so when planning a study, aim for more than the minimum.

4.4.1 Convergence

If there is a convergence problem, you should usually get a warning. Other signs of convergence problems may be RE estimates that are zero, CIs that are extremely large, or strong correlations in the correlation matrix of the predictors that is reported by summary(). Here, we have no problems, but we’ll see examples of this as we go on.

There are different types of convergence problems that you can encounter:

  • Warnings about scaling and centering -> just do it, it doesn’t cost you!
  • The warning “boundary (singular) fit: see help(‘isSingular’)” (meaning that some dimensions of the variance-covariance matrix have been estimated to zero. -> often, this just means that a RE estimate is zero. In many cases, this is not a problem and can actually be ignored, but it is hard to give general advice to when this is the case. With few levels in the grouping variable, however, a singular fit can inflate the type I error of the fixed effects (Oberpriller, Souza Leite and Pichler, 2022); see the recommendations in Section 4.3.3. In random slope models, it often helps to move from | to || (suppressing the correlation). Removing the RE will solve the problem, but could lead to type I error inflation. A more conservative solution would be to change the RE to a fixed effect

Tip 4.3: Conditional, unconditional and marginal predictions

For mixed models, there are three ways to make predictions, which are easy to confuse:

  • Conditional predictions include the estimated random effects, i.e. they are the predictions for the particular groups in the data (re.form = NULL in lme4, the default).
  • Unconditional predictions use only the fixed effects, i.e. the random effects are set to zero (re.form = NA or re.form = ~0). This is the prediction for an “average” group.
  • Marginal predictions are averaged over the distribution of the random effects, i.e. the mean prediction over all possible groups.

In a linear mixed model, unconditional and marginal predictions are identical, because the random effects average to zero. With a nonlinear link function (GLMMs), they differ (see Section 9.5.1). Note that these terms are not used consistently in the literature and in R packages; e.g. the “marginal R2” of mixed models (Section 4.5.4) is based on the fixed effects only.

Tip 4.4: Conditional vs. unconditional predictions and residuals

When you predict with a random effect model, you can do conditional or unconditional predictions (see Tip 4.3). The difference is that conditional predictions include the REs, while unconditional predictions only include the fixed effects.

predict(mod1, re.form = NULL) # conditional, default
predict(mod1, re.form = ~0) # unconditional

This also makes a difference for the residual calculations: in principle, you could calculate residuals with respect to both predictions. In lme4, however, residuals() always returns conditional residuals (observed minus conditional predictions). It has no re.form argument, and additional arguments are silently ignored, so residuals(mod1, re.form = ~0) would still give conditional residuals. Unconditional residuals have to be calculated by hand with predict():

residuals(mod1) # conditional
Exam$normexam - predict(mod1, re.form = NULL) # conditional, same as residuals(mod1)
Exam$normexam - predict(mod1, re.form = ~0) # unconditional

DHARMa offers both: since version 0.5.0, simulateResiduals() simulates conditional on the fitted random effects by default, and with simulateREs = "unconditional" it re-simulates them. Both have advantages and disadvantages:

  1. Conditional residuals are more sensitive to violations of the iid normal assumptions of the outer (observation-level) normal error
  2. However, REs can sometimes absorb misfit, such that plotting conditional residuals ~ pred looks fine, but unconditional ~ pred does not. For that reason, if you only check conditional residuals, you should also check REs ~ pred (see Section 4.4.4)

4.4.3 Normality of REs

I prefer to look at this visually. You can also run a shapiro.test() to check if you should consider the pattern at all, but interpret it visually: such tests are over-sensitive for large n and underpowered for few groups.

Question is how bad can this be? (Neuhaus, McCulloch and Boylan, 2013) report some simulation results that suggest that fixed effect slopes (bias, coverage) are relatively robust to misspecification in the RE distribution, which is reassuring.

4.4.4 Correlation of REs with predictors

As mentioned in Tip 4.4, REs can sometimes absorb misfit of the fixed effect structure. It can therefore be useful to check if there is a correlation with the predictors, especially if you only check conditional residuals. Example:

y = aggregate(standLRT ~ school, FUN = mean, data = Exam)
plot(x$school$`(Intercept)` ~ y$standLRT)

A trend of the school intercepts with the school mean of a predictor means that the RE absorbs an effect that should be in the fixed part. Here, there is a weak positive trend (correlation about 0.35): schools with a higher average reading score tend to have higher intercepts. A common remedy is to add the school mean of the predictor as an additional fixed effect (in Exam it already exists as schavg), which separates the within-school from the between-school effect.

4.4.5 Residual pattern per group

lme4 has an excellent plot syntax to plot residuals per grouping factor. Check out the help of plot.merMod. The following plot shows residuals ~ fitted for each school

Looks still good to me, but if we think we see a pattern here, we should introduce a random slope.

4.5 Downstream analysis of mixed models

Specifying mixed models is quite simple, but their practical application raises several issues (degrees of freedom, model selection, ANOVA, predictions). The following table gives an overview of how to obtain tests and confidence intervals for mixed models; the subsections of this section explain the details. The columns for glmer and glmmTMB become relevant for generalized linear mixed models (Section 9.5).

All of these are approximations, because the degrees of freedom of a mixed model are not clearly defined (Section 4.5.1). With few groups (as a rule of thumb, fewer than about 10-20), Wald tests and also likelihood ratio tests with the standard \(\chi^2\) distribution give p-values for fixed effects that are too small. For linear mixed models, the approximate degrees of freedom of lmerTest (Satterthwaite) or Kenward-Roger (car::Anova(m, test.statistic = "F")) are then more reliable; for GLMMs, use a parametric bootstrap or a simulated LRT (DHARMa::simulateLRT(), pbkrtest::PBmodcomp()), and profile instead of Wald CIs. In contrast, a standard likelihood ratio test for a random effect is conservative, because the null hypothesis (variance = 0) lies at the boundary of the parameter space, which is another reason to use the simulated LRT. Finally, note that anova() after loading lmerTest gives type III tests, while car::Anova() gives type II tests by default; with interactions, they test different hypotheses (Section 3.2.3, Caution 4.2), so say which one you report.

4.5.1 Degrees of freedom for a random effect

Possibly the most central problem is: How many parameters does a random effect model have?

Note

Why is it so important to know how many parameters a model has? The answer is that what seems like a very minor point is needed in all the mathematics for calculating p-values, AIC, LRTs and all that, so without knowing the complexity of the model, the mathematics that is used in lm() breaks down.

We can make some guesses about the complexity of an LMM by looking at its fixed effect version counterparts:

mFix0 = lm(normexam ~ standLRT + sex , data = Exam)
mFix0$rank # 3 parameters.

mRE = lmer(normexam ~ standLRT + sex +  (1 | school), data = Exam)
# No idea how many parameters.

mFixSchool = lm(normexam ~ standLRT + sex + school, data = Exam)
mFixSchool$rank # 67 parameters.

So, we see that the fixed effect model without school has 3 parameters, and with school 67. It is reasonable to assume that the complexity of the mixed model is somewhere in-between, because it fits the same effects as mFixSchool, but they are constrained by the normal distribution.

The width of this normal distribution is controlled by the estimated variance of the random effect. For a high variance, the normal is very wide, and the mixed model is nearly as complex as mFixSchool; but for a low variance, the normal is very narrow, and the mixed model it is only as complex as mFix0. The shrinkage plot in Section 4.3.2 shows this directly: the more the random estimates are pulled towards the grand mean, the fewer effective parameters the model uses.

Note

Technically, the mixed model mRE estimates the same 65 school effects as the fixed effect model mFixSchool, plus one more parameter, the standard deviation of the random effects. Could it thus ever be more flexible than mFixSchool? The answer is no - the RE standard deviation is what is technically called a hyperparameter. It is not an effect that is estimated, but rather a parameter that controls the freedom of the estimated effects, so the effective number of parameters of the mixed model can never exceed that of mFixSchool.

Because of these issues, lmer by default does not return p-values (for an overview of the options, see Table 4.1). The help advises you to use bootstrapping to generate valid confidence intervals and p-values on parameters. This is possible indeed, but very cumbersome.

However, you can calculate p-values based on approximate degrees of freedom via the lmerTest package, which also corrects ANOVA for random effects, but not AIC.

4.5.2 Predictions

Related to the interpretation of an RE is the question whether the REs should be included when you make predictions or calculate other outputs of the model, e.g. residuals.

  • Unconditional predictions = predictions without the RE, i.e. the population-level curve from the fixed effects (see Tip 4.3)

  • Conditional predictions = predictions with RE

In some, but unfortunately not all packages, the predict function can be adjusted. In lme4, this is via the option re.form, which is available in the predict and simulate function. Let look again at a simple random intercept model

m = lmer(normexam ~ standLRT + sex +  (1 | school), data = Exam)

To generate predictions from this model, use the following syntax.

predict(m, re.form = NULL) # include all random effects
predict(m, re.form = ~0) # include no random effects, identical re.form = NA
predict(m, re.form = ~ (1|school)) # condition ONLY on 1|school

The third option is in this case identical to the first, but if we would add more REs to the model, it would differ.

A second issue with predictions is their uncertainty. pred <- function(m) predict(m,re.form = NA)

  • We could add the argument newdata if we wanted to predict to newdata

4.5.3 Model selection and hypothesis tests with mixed models

For model selection, the degrees of freedom problem (Section 4.5.1) means that normal model selection techniques such as AIC or naive LRTs don’t work on the random effect structure, because they don’t count the correct degrees of freedom.

4.5.3.1 Selecting on fixed effects

The easy part is the selection on the fixed effect structure - if we can assume that by changing the fixed effect structure, the flexibility of the REs doesn’t change a lot (you would see this by looking at the RE sd), we can use all standard model selection methods (with all their caveats) as before on the fixed effect structure. All I will say about model selection on standard models applies also here: good for predictions, rarely a good idea if your goal is causal inference (see Section 8.3.1 and the chapter on causal inference, Chapter 7).

CautionCareful when selecting on models fit with REML

As discussed in Section 4.2.4, LMMs are per default fit with REML, whose likelihoods are not comparable between models with different fixed effects. When comparing models with different fixed effects via LRTs or AIC, refit the models with ML; anova() does this automatically (it prints “refitting model(s) with ML”), AIC() and logLik() do not. See also (Verbyla, 2019)

Verbyla, A.P. (2019) “A note on model selection using information criteria for general linear models estimated using REML,” Australian & New Zealand Journal of Statistics, 61(1), pp. 39–50. Available at: https://doi.org/10.1111/anzs.12254.

4.5.3.2 A priori selection on random effects

When changing the RE structure, you should not use standard AIC or LRTs, because of the df problem. For that reason, I would generally recommend to fix the RE structure a priori and keep selection on REs to a minimum.

What structure you should choose may depend on the experimental setting and scientific / biological expectations, but a base recipe for a limited number of data is:

  1. add random intercept on all obvious grouping variables
  2. check residuals per group (e.g. with the plot function in Section 4.4.5), or simulated LRT (see Section 4.5.3.3) and add random slope if needed
m1 <- lmer(y ~ x + (1|group))

plot(m1, 
     resid(., scaled=TRUE) ~ fitted(.) | group, 
     abline = 0)

I would deviate from this recipe and also add random slopes a priori when I either have sufficient power to support the random slopes without problems, or have good a priori reasons to expect random slopes.

4.5.3.3 Simulated LRTs

If you want to formally select on the variance structure, the best way is to use a simulated likelihood-ratio test (LRT), based on the parametric bootstrap, which we introduced in Section 3.2.2. In such a test, we make the same assumptions as in a standard LRT, which is:

  1. We want to compare 2 nested models M0, M1
  2. H0: simpler model M0 is correct
  3. Test statistic: M1/M0 or log(M1/M0) = log(M1) - log(M0)

However, unlike in the standard LRT, where we assumed that the test statistic is Chi2 distributed, we use the parametric bootstrap (see Section 2.12.2) to generate new data under H0, fit M0 and M1 to this simulated data, and thus generate a null distribution of the LR for these two models.

Simulated LRTs for mixed models are implemented in a number of packages. To my knowledge, one of the most general functions is DHARMa::simulateLRT. Here an example, in which we test if a random intercept is needed. Note that we fit the mixed model with ML (REML = FALSE), because its likelihood is compared to the likelihood of a model without random effects (see Section 4.2.4):

set.seed(123)
dat <- DHARMa::createData(sampleSize = 200, randomEffectVariance = 1, family = gaussian())

library(lme4)
m1 = lmer(observedResponse ~ Environment1 + (1|group), data = dat, REML = FALSE)
m0 = lm(observedResponse ~ Environment1 , data = dat)

TipHand-coded simulated LRT

We use the models from the previous example - first, let’s look at the observed LR

observedLR = logLik(m1) - logLik(m0)

The log LR of m1 (the RE model) over m0 is 45, meaning that seeing the observed data under m1 is exp(45) times more likely than under m0.

As noted, the complex model will always fit better, so it is expected that the data is more likely under M1, but is the increase significant? In this case, the LR is actually so large that we actually wouldn’t need to test. A rough rule of thumb is that you need a log LR of 2 for each df that you add, and here we have an RE with 10 groups, so even if we counted 1 df for each RE group, this should be easily significant. Nevertheless, let’s do the formal test, and this time by hand.

First, we write a function that creates new LRs under H0, by simulating new data from the fitted M0, and re-fitting M0/M1 to this data, and return the LR.

resampledParameters = function(){
  newData = dat
  newData$observedResponse = unlist(simulate(m0))
  mNew0 = lm(observedResponse ~ Environment1, data = newData)
  mNew1 = lmer(observedResponse ~ Environment1 + (1|group), data = newData, REML = FALSE)
  return(logLik(mNew1) - logLik(mNew0))
}

Now, let’s generate the null distribution. There will be a lot of warnings which you can usually ignore. The reason is that we simulate the data under H0, i.e. with no RE, and thus the mixed model estimates the RE variance to zero, which creates a warning.

nullDistribution = replicate(500, resampledParameters())

If we plot the null distribution, we see that if the data would really not have an RE, we would expect an increase of likelihood for the more complicated model of not more than 4 or so.

hist(nullDistribution, breaks = 50, main = "Null distribution log(L(M1) / L(M0))")

However, what we actually observe is an increase of 45. I rescaled the x axis to make this visible.

hist(nullDistribution, breaks = 50, main = "Null distribution log(L(M1) / L(M0))", xlim = c(-5,50))
abline(v = observedLR, col = "red")

No simulated LR exceeded the observed one, so p < 1/501 (about 0.002); a Monte Carlo p-value is never exactly 0.

Caution 4.2: Type III ANOVA for mixed models: coding and centering

The considerations from the chapter on ANOVA about contrasts and centering (Section 3.2.4, Caution 3.1) also apply to mixed models, with one difference between packages: the type III ANOVA of lmerTest does not depend on how factors are coded (it constructs the type III hypotheses independently of the contrasts used), but car::Anova(fit, type = "III") does, exactly as for an lm. Both still depend on centering: if a numeric predictor is part of an interaction, the main effects of the other variables are tested at the value 0 of this predictor. emmeans::joint_tests() also works for mixed models and avoids both problems. When reporting, state which method was used for the degrees of freedom (Satterthwaite as above, or Kenward-Roger).

Note also that in mixed models, the coding determines what random slopes for factors mean. If you use uncorrelated random effects (the || syntax), the coding even changes the fitted model, as the assumption of zero correlations depends on how the factor is coded.

Another common question in ANOVA for mixed models is how much R2 is explained by fixed vs. random effects. Philosophically, the main point of discussion here is: Do you want to count the random effect variance as “explained”, or “residual”. In any case, a common approach is the marginal and conditional R2 proposed by Nakagawa and Schielzeth (2013) and Nakagawa, Johnson and Schielzeth (2017), which is implemented in the MuMIn package. With this, we can run

Interpretation

  • R2m: Marginal R2 value associated with fixed effects (the name is historical; in the terminology of Tip 4.3, it is based on the unconditional predictions).
  • R2c: Conditional R2 value associated with fixed effects plus the random effects.

It is important to note that this is a description of the fitted model, not necessarily valid inference - the reason is that if you add a lot of REs, you will tend to get a lot of variance explained by the RE structure. If you want to correct for this, one option is to calculate R2 values under a cross-validation.

4.5.5 Variance partition coefficients (VPCs)

An interesting variation of using mixed models is to use them as an alternative to ANOVA to understand how much variation in a response variable is explained by different factor variables (for applications in ecology, see (Leite et al., 2024)). Consider the following example of simulated data, where I created 3 categorical variables with an increasing number of levels per variable, and essentially a “normal” distribution of effects for the different levels of those. In other words, these are exactly the assumptions of a mixed model, where we have 4 normally distributed errors: 3 for the 3 groups (with different group sizes) and 1 residual error, all with the same sd of 1.

TipVPC vs. ANOVA

So, when and why should you prefer VPC over ANOVA?

A considerable advantage of the VPCs over ANOVA is that they compute orders of magnitudes faster than a standard anova in large datasets with many group levels.

Disadvantages are measures of uncertainty (p-values, CIs) may be problematic to obtain. Moreover, you should also note that the estimation of the VPCs depends on the ability of the mixed models to estimate the correct RE variance. To obtain unbiased estimates of the RE variance is notoriously difficult, as evidenced by the different methods to estimate the RE variances in different packages, as well as the REML / ML estimation debate (see Section 4.2.4). The issues are usually not a primary concern, because we usually do not interpret the RE variances directly, but they are only indirectly used to account for the group level effects. In the VPC analysis, however, they are directly used, and thus particular care should be taken, e.g., in checking if RE distributions are indeed normal etc. (see, e.g., Section 4.4.3).

4.6 Take-home messages

Tip
  1. Model a grouping variable as a random effect if you are not interested in its individual estimates: it accounts for the correlation within groups and uses fewer df than a fixed effect. Use a fixed effect if you need unbiased group estimates, because random effect estimates are shrunk towards the grand mean.
  2. Fix the random effect structure a priori (random intercepts for all grouping variables; random slopes if expected or if the residuals per group suggest them). Do not select it with AIC or standard LRTs, because the df of a random effect are unclear; use a simulated LRT if you need a test.
  3. Check that group IDs are unique across higher-level groups, or use the nested syntax (1 | group / subgroup); otherwise different groups are merged.
  4. Fit with REML, but refit with ML when you compare models with different fixed effects by LRT or AIC. lmer() reports no p-values because of the df problem; use lmerTest (approximate df) or the parametric bootstrap.
  5. Check the residuals as for an lm, plus convergence (center and scale predictors; a singular fit often means a variance estimated at zero; for grouping variables with few levels, see Section 4.3.3) and the random effects (normality, correlation with predictors). State whether predictions and residuals are conditional or unconditional, and use the parametric bootstrap for confidence intervals of predictions.

4.7.2 College student performance

The GPA (college grade point average) data is a longitudinal data set (also named panel data, German: “Längsschnittstudie”. A study repeated at several different moments in time, compared to a cross-sectional study (German: “Querschnittstudie”) which has several participants at one time). In this data set, 200 college students and their GPA have been followed 6 consecutive semesters. Look at the GPA data set, which can be found in the EcoData package:

library(EcoData)
str(gpa)

In this data set, there are GPA measures on 6 consecutive occasions, with a job status variable (how many hours worked) for the same 6 occasions. The response is the college gpa. There are two student-level explanatory variables: the sex (male / female) and the high school GPA (highgpa). There is also a dichotomous student-level outcome variable, which indicates whether a student has been admitted to the university of their choice. Since not every student applies to a university, this variable has many missing values. Each student has an id; year (1-3) and semester (1-2) together define the six occasions.
